# Gorilli mascot

Mascot renders used across Gantry's README and docs. They belong to Gorilli and are not covered by the MIT license of the code; do not reuse them outside this project without permission.

| File          | Mood            | Used for                             |
| ------------- | --------------- | ------------------------------------ |
| `wave.webp`   | waving          | banner, logo, approval, contributing |
| `think.webp`  | thinking        | pipeline, docs index                 |
| `banana.webp` | eating a banana | install, idempotency                 |
| `hype.webp`   | cheering        | benchmark, rate limits               |
| `sleep.webp`  | asleep          | timeouts, fake clock                 |

`*-160.webp` are small versions embedded in the SVGs. Regenerate the SVGs with `npm run brand`.
